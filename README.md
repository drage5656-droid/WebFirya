# WebFirya

Большая интерактивная учебная веб-лаборатория на React и Vite. В проекте есть двуязычный интерфейс, светлая и тёмная темы, HTML/CSS/JavaScript-песочницы, анимированный фон, галерея с просмотром изображений и адаптивная навигация.

## Запуск

В терминале VS Code, открытом в этой папке:

```powershell
npm install
npm run dev
```

Открой адрес, который Vite покажет в терминале (обычно `http://localhost:5173/`).

Для production-сборки выполни `npm run build`. Готовый сайт появится в папке `dist`.

## Структура

- `index.html` — HTML-точка входа; подключает `main.jsx`.
- `main.jsx` — подключает React-приложение и `index.css`.
- `App.jsx` — собирает разделы и управляет темой, языком и анимацией появления блоков.
- `Header.jsx`, `Hero.jsx`, `LangCard.jsx`, `Gallery.jsx`, `Footer.jsx`, `SEO.jsx` — компоненты интерфейса.
- `SiteEffects.jsx`, `ScrollProgress.jsx` — лёгкий canvas-фон и индикатор прокрутки.
- `langs.js` — тексты, подсказки и стартовый код карточек языков.
- `public/images/` — иконки языков и фотографии галереи; Vite копирует их в production-сборку.
- `index.css` — адаптивные стили и светлая/тёмная темы.
- `vite.config.js` — настройки dev-сервера и сборки.
